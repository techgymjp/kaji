# 刀鍛冶 ― 日本刀づくり

日本刀職人（刀匠・研師）の作業工程を再現したブラウザゲームです。
折り返し鍛錬から銘切りまで七つの工程をたどり、世界に一振りの日本刀を打ちます。

## 工程

| 工程 | 内容 | 操作 |
| --- | --- | --- |
| 一、積み沸かし・折り返し鍛錬 | ふいごで鋼を沸かし（約1300℃）、鎚で打って折り返す。8〜15回 | Space長押し / Enter / Space |
| 二、造り込み | 皮鉄と心鉄を組み合わせる（甲伏せ・本三枚・丸鍛え）。中央に組み、沸かし付けで鍛着させる | Space / クリック、Space長押し / Enter |
| 三、素延べ・火造り | 鋼を打ち延ばし、目標の厚みに揃える。冷えたら火床へ戻す | クリック/タップ、1・2・R |
| 四、土置き | 焼刃土を置いて刃文を描く（自作 or 型） | ドラッグ |
| 五、焼入れ | 暗い鍛冶場で刀身の「月の出の色」を見極めて水へ入れる | Space / ボタン |
| 六、研ぎ | 備水砥→改正名倉砥→内曇砥。速度を保って研ぐ | 左右にドラッグ |
| 七、銘切り | 茎に刀工名と年紀を刻む | 文字入力 |

最後に「切れ味・強靭さ・美しさ」が鑑定され、最上大業物〜鈍刀の位が付きます。
打った刀はブラウザの「蔵」（localStorage）に保存されます。

## 技術

- HTML / CSS / JavaScript（ビルド不要・外部ライブラリなし）
- 刀身・赤熱した鋼・火床はすべて Canvas 2D で描画
  - 鋼の発光色は黒体放射の色温度に基づく（暗赤 → 桜色 → 月の出の色 → 橙 → 沸き）
  - 刀身は断面の稜（鎬）ごとの明暗、板目肌、刃文の匂口・沸・足、映りを重ねて表現
- 効果音は Web Audio API で合成

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` に設定してください。

## ローカルで遊ぶ

`index.html` をブラウザで開くか、簡易サーバーを起動します。

```bash
python3 -m http.server 8000
```
