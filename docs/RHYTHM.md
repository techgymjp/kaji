# 刀鍛冶 リズムのパターン一覧

師匠（横座）が 1 小節リズムを叩いて聴かせ、次の 1 小節で同じリズムを返します。
リズムは毎回、下の型の中からランダムに選ばれます。4 分音符と 8 分音符だけでできています。

- 譜面の読み方：1 小節は 4 拍。1 拍を 2 つ（8 分音符）に分け、`●` で叩き、`・` で休みます
- 口で言うと：1 拍ごとに「タン」（拍の頭だけ）・「タタ」（頭と裏）・「ウタ」（裏だけ）・「ウン」（休み）
- 判定：会心 ±60ms、良し ±110ms、それより外れた ±180ms までは「ずれ」
- 出来の値（1 ミリ秒ごとに細かく刻む）：会心 1.00（0ms）→ 0.85（60ms）／良し 0.85 → 0.55（110ms）／ずれ 0.55 → 0.15（180ms）／見逃し 0

## どの場面で、どの型を使うか

| 場面 | テンポ | 伸ばす・締める小節 | 切れ目・折り返し・鍛着の小節 |
| --- | --- | --- | --- |
| 皮鉄の鍛錬 1 回目 | 100 BPM | やさしい型 | 折り返しの型 1（固定） |
| 皮鉄の鍛錬 2 回目 | 102 BPM | やさしい型 | 折り返しの型 |
| 皮鉄の鍛錬 3・4 回目 | 104・106 BPM | ふつうの型 | 折り返しの型 |
| 皮鉄の鍛錬 5 回目 | 108 BPM | むずかしい型 | 折り返しの型 |
| 心鉄造り | 108 BPM | ふつうの型 | ― |
| 造り込み | 108 BPM | 曲げの型 → 締め・鍛着の型 | ― |
| 打ち延ばし（前半・後半） | 110・112 BPM | ふつうの型 → むずかしい型 | 切先の型 |

折り返しの小節は、4 打が順に「切れ目（鏨）→ 折り返し → 鍛着 → 鍛着」になります。
